# Motionmaker

Frame-exact motion graphics with Claude Code: one `/motionmaker` command that interviews you, confirms a frame-locked brief, renders, reviews, adds synthesized sound and exports MP4/GIF, or code (a TypeScript player and a React component) for websites and apps.

## Motionmaker: install

Pick one. All three give you the same thirteen skills; then start Claude Code and type **`/motionmaker`**.

**A. Claude Code plugin (one step, auto-updatable)**
```
/plugin install motionmaker --marketplace Adamkyl69/motionmaker
```
(or in a terminal: `claude plugin marketplace add Adamkyl69/motionmaker` then `claude plugin install motionmaker@motionmaker`). Needs a Claude Code version with plugin support; the manifests pass `claude plugin validate --strict`.

**B. CLI installer (copies the skills into `~/.claude/skills` or your project)**
```
npx github:Adamkyl69/motionmaker install            # global: ~/.claude/skills (or $CLAUDE_CONFIG_DIR/skills)
npx github:Adamkyl69/motionmaker install --project  # this project only: ./.claude/skills
npx github:Adamkyl69/motionmaker install --dry-run  # show what would happen, change nothing
```
Other commands: `update`, `uninstall`, `list`, `doctor` (checks node, ffmpeg, Chromium, Playwright; never installs), and `setup [dir] [--3d] [--browser]` (npm-installs Playwright into your working folder, plus `three` and `gsap` with `--3d`, and downloads Playwright's Chromium with `--browser`). It only ever touches the skill folders it ships; a folder it did not install, or one you edited, is skipped unless you pass `--force`, and then the old one is kept as `<name>.bak-<timestamp>`. `uninstall` removes only what it installed. (From a clone: `node bin/cli.mjs install`.)

**C. Manual:** copy the folders in `skills/` into `~/.claude/skills/` (keep them together; they call each other's scripts).

**Want to test it on your machine? See [TESTING.md](TESTING.md).**

**Then, once per working folder:** `npx github:Adamkyl69/motionmaker setup --3d --browser` (or `npm i playwright` yourself; `three@0.160.0 gsap@3.12.5` only for the 3D and GSAP templates), and make sure `ffmpeg` is on your PATH. `/motionmaker` runs a preflight and tells you what is missing; it never installs anything on its own.

## Motion skill set (`skills/`)
Make frame-exact motion graphics with Claude. The method is distilled from public write-ups listed under Credits.

**Start with `/motionmaker`.** One command that checks your toolchain, interviews you (what, where it is posted, length/loop, sound, words, look, feel), shows a brief for your OK, then builds, reviews (render-look-fix, `check.mjs`), exports MP4/GIF and writes `PROMPT.md` + `RECEIPTS.md` to `motion-out/<slug>/`. It runs a small creative team: you talk to one command, and an **art director** (`motionmaker-art-director`) asks the creative-brief questions, shows three directions on real pixels, locks a visual system and critiques every round. It drives the twelve skills below.

| Skill | Stage | Ships |
|---|---|---|
| `motionmaker` | **the command**: preflight, guided intake, brief gate, build, review, sound, export, deliver | `scripts/preflight.sh`, `scripts/scaffold.sh`, 16 templates: `style-scene` (6 art styles), `title-loop`, `logo-reveal`, `data-chart`, `product-demo` (20 s launch clip), `three-product` (Three.js), `gsap-kinetic` (seeked GSAP timeline), `lottie-scene`, `rive-scene`, `illustration-scene`, `footage-scene`, `code-reveal`, `equation-scene`, `map-scene`, `annotate-scene`, `icon-features` |
| `motionmaker-art-director` | **art direction**: creative-brief questions in onboarding, 3 directions as real style frames to choose from, visual system + motion language (AD-BRIEF.md), per-round critique, poster-frame sign-off | `looks/looks.json` (8 looks), `styles/` (6 art styles with cards and honest ratings) + `scripts/styles.mjs` (suggest, side-by-side style frames), `scripts/directions.mjs`, `critique.mjs` (contrast, margins, negative space, focal point, competing elements), `palette.mjs`, `type-scale.mjs`, `looktests.sh` (grayscale / squint / thumbnail), `craft/principles.md`, `craft/critique-checklist.md`, `AD-BRIEF-template.md` |
| `motionmaker-anatomy` | **explain how something works as a working machine**: Anatomy (MIT, by Ryan, separate install) builds an interactive isometric figure; we direct the shots (hover, drag, clicks, idle tour) and film it frame-exactly, or put it **live on a website** where visitors take it apart themselves | `anatomy.mjs` (where, install, inspect, film, web) on top of `film-realtime.mjs` and `export-web.mjs --live` |
| `motionmaker-montage` | **footage, AI video, voice, avatars**: routes those requests to a separately installed OpenMontage (AGPLv3, not bundled) with our brief, budget cap and gates, imports the film with its asset provenance, adds our cards and runs our QA | `montage.mjs` (route, check, handoff, import, finish) |
| `motionmaker-libs` | **optional libraries, installed on request**: a real open-licence font per look (identical type on every machine, Turkish/accented/Cyrillic included), code reveals (Shiki), equations (KaTeX), globe routes (d3-geo + Natural Earth), hand-drawn marks (Rough.js, fixed seed), four icon sets (Lucide, Tabler, Phosphor, Material Symbols) | `lib.mjs` (list, setup), `fonts.mjs`, `code.mjs`, `math.mjs`, `icons.mjs`, `smoke.sh` (builds and checks every template), `libs.json` |
| `motionmaker-assets` | **illustration kits and ready-made animation**: Open Peeps and Humaaans characters built locally (CC0), LottieFiles, Rive, unDraw; inspected as untrusted input, recoloured to the brand (skin tones protected), rendered frame-exact, tracked in a licence ledger with required credits | `kit.mjs` (setup, list, peep, human), `footage.mjs` (frame-exact screen recordings), `inspect-asset.mjs`, `recolor.mjs`, `ledger.mjs` (add, check, credits, report), `licenses.json`, `craft/illustration.md` |
| `motionmaker-reference` | analyze a reference video: probe, 2/s overview, frames around events, REFERENCE.md (measured / estimated / proposed) | `analyze-reference.sh`, `around.sh`, `beat-grid.mjs` (tempo from the cuts), `reference-template.md` |
| `motionmaker-catalog` | match a described motion to a named technique (awesome-ai-motion: 637 cards, 11 recipes) and run its examples through our pipeline | `catalog.mjs` (search, show, recipes, adopt), `sweep.mjs` (catalog-wide health check) |
| `motionmaker-brief` | directed prompt + frame-locked BRIEF.md, feelings -> numbers, ban list | `timeline.mjs` (seconds <-> frames, global <-> scene-local, reading-hold check), `BRIEF-template.md` |
| `motionmaker-engines` | pick the engine/repo (Three.js, drei, Remotion, HyperFrames, GSAP, Motion, Fabric, Rive, deck.gl, cobe, confetti, twgl, ffmpeg.wasm) | |
| `motionmaker-build` | render contract, deterministic program, frame renderer; **export as code** for websites and React apps | `export-web.mjs` (a finished piece as a deploy folder + `motion-player.ts` and `Motion.tsx`, frame-exact; `--live` for real-time pages), `render.mjs` (HTTP-served, software WebGL2, optional motion blur, `--size auto`), `film-realtime.mjs` (films any real-time web page: virtual clock, scripted input, CPU raster, `--check` proves two films identical), `browser.mjs`, `tokens.js`, `numbers.md` |
| `motionmaker-review` | render-look-fix loop, four-field corrections, fixes table | `stills.mjs` (specific frames/ranges), `contact-sheet.sh`, `check.mjs` (clock/random scan, determinism, seam duplicate, page errors), `film-gate.mjs` (finished-film gate: dead stretch, blank stretch, blue-purple), `review-pack.mjs` (independent reviewer with only the film), `deliver.mjs` (refuses on red, sealed DELIVERY.md, `--verify`), `CORRECTIONS.md` |
| `motionmaker-sound-export` | synthesized frame-synced sound (Web Audio), loudness, sync verification, X export, export probe | `synth.mjs` (hits + kick/hat/note voices), `beat.mjs` (grid, snap, start-on-beat, beat-grid music ducked under hits), `loudnorm.sh`, `verify-sync.mjs`, `export.sh`, `probe.sh` |

What was tested end to end here: all 16 templates (style-scene in all 6 styles) render and pass `check.mjs`, and `motionmaker-libs/scripts/smoke.sh` re-runs them (24 checks including `film-realtime.mjs` and both web exports). The renderer uses CPU raster and compositing by default (set `MOTIONMAKER_GPU=1` to opt out): with GPU raster on software GL a frame could differ by a few pixels between runs, and the old workaround of capping opacity at 0.999 is gone; renders are also about 26% faster; a 600-frame 1080x1080 launch clip with synthesized sound exports to an MP4 that `probe.sh` and `verify-sync.mjs` pass (hits within 0.05 frame of the target, loudness about -15 LUFS at -1.0 dBTP, AAC round trip included). The awesome-ai-motion catalog was swept with your approval in a sandboxed browser (non-local requests blocked): all 128 effects and 11 recipes run through our renderer with 0 failures; 2 effects (`pie-donut-update`, `sequence-message-draw`) are order-dependent and must be rendered once, in order (details in `motionmaker-catalog/SKILL.md`).
Asset scenes: Lottie loops and Rive loops were checked to wrap exactly (frame f equals frame f plus one cycle) and to differ within a cycle; the inspector blocked a hostile SVG (script, handlers, external URL) and a Lottie with remote images; the ledger fails on unrecorded files, unknown licences and missing CC BY credits. Real-time filming: two Anatomy figures (dial indicator, Raptor engine with its WebGL plume) and our own fixture film identically twice; getting there took a virtual IntersectionObserver, an input gate against Chrome's synthetic hover events, CPU raster and compositing (GPU raster on software GL varied by a few pixels), and a setInterval fix found by the fixture. Quality gates: the finished-film gate separates frozen, blank and blue-purple test films from all of our templates; it caught a real 6.2 s frozen hold in our own product-demo (fixed), and three rounds of independent review caught a squashed picture on non-square sizes, dark-on-dark UI text, a blank frame at a cut and a red "success" tick (all fixed); the remaining review notes on that template are about placeholder copy and pacing, which a real brief replaces. Beat grid: tempo recovered exactly from a 120 BPM cut test; music + picture hits verified in sync and >= 8 dB clear of the music. Art styles: 4 rated three stars, 2 two stars (Matisse, ukiyo-e), with their weaknesses in their cards. The OpenMontage bridge was tested against its documented layout and manifest schema with a mock project, NOT a live OpenMontage run (installing it in this environment was blocked). Libraries: footage extraction was checked exact to the frame (a video encoding its own frame number); bundled fonts were checked on all 8 looks and with Turkish text; every library template renders identically when frames are drawn out of order. Not tested: other Lottie/Rive files than the two used, state machines (not supported), Windows/macOS.
Code export: every piece can also ship as code for websites and React apps. `export-web.mjs` was run with `--check` on all 16 templates (21 pieces including every art style): 5 sample frames per piece through the player are pixel-identical to the renderer's, and play, pause, loop, the end of a non-looping piece and reduced motion pass. The React component was tested in a React 18 StrictMode app (esbuild bundle), typechecked against React 18 and 19, with the piece on another origin and with the `<motion-clip>` element; `fit` contain and cover were measured. The live mode was tested on our fixture and Anatomy's dial and Raptor examples. Testing it found and fixed: a file-name clash (`motion.ts` and `Motion.tsx` resolve to the same file on Windows and macOS), React passing `undefined` over the defaults, and a frame scheduler that doubled every frame until the Raptor froze. Not tested: Next.js and Vite builds end to end, Safari and Firefox, a real GPU.
Optional libraries: `npx github:Adamkyl69/motionmaker setup --libs fonts code math maps sketch icons` (or later, `node <skills>/motionmaker-libs/scripts/lib.mjs setup <group>`).
Setup: `npm i playwright` in the working directory (plus `three@0.160.0 gsap@3.12.5` for those two templates), ffmpeg on PATH, `CHROMIUM=<path>` if Chromium is not at `/opt/pw-browsers/chromium`.

Worked examples: `demo/` (Launch day loop).
